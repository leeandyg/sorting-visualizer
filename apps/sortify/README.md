## Keyboard

| Key | Does |
|---|---|
| Space | Play or pause |
| ← / → | Step back or forward (Shift: 5 steps) |
| Q / E | Start or end of the song |
| − / = | Slower or faster |
| M | Sound on or off |
| Enter | Play the array in the top bar |
| Shift+Enter | Expand the array field |

## Running it

From the repo root:

```sh
npm install
npm run dev:sortify    # http://localhost:5174
```
